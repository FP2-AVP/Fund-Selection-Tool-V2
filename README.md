# คู่มือการใช้งาน Fund Selection Tool for FP2

ระบบคัดเลือก เปรียบเทียบ และบันทึกผลการวิเคราะห์กองทุนสำหรับ Financial Planner รุ่นที่ 2

> คู่มือนี้แสดงอยู่ในเมนู **คู่มือการใช้งาน** ของระบบโดยตรง การแก้ไขไฟล์ `README.md` จะเปลี่ยนเนื้อหาคู่มือบนหน้าเว็บหลังรีเฟรช

---

## 1. เริ่มต้นใช้งาน

1. เปิดระบบผ่าน Web Server เช่น `http://localhost:8080` ห้ามเปิด `index.html` ด้วย `file://` โดยตรง
2. กด **เข้าสู่ระบบด้วย Google** และเลือกบัญชีองค์กรที่มีสิทธิ์อ่าน Google Sheets ที่ระบบใช้งาน
3. รอให้หน้า **แดชบอร์ด** แสดงผล และตรวจสอบ Quarter ที่มุมบนของ Sidebar
4. เลือก Quarter ที่ต้องการก่อนเริ่มคัดเลือกหรือเปรียบเทียบข้อมูล

ระบบใช้โหมด `google_first` คืออ่าน Google Sheets ก่อน และใช้ Local JSON เป็นข้อมูลสำรองเมื่ออ่าน Google Sheets ไม่สำเร็จ ข้อมูลตั้งต้นปัจจุบันคือ `2026-Q1`

### การเลือก Quarter

- ระบบจะแสดงเฉพาะ Quarter ที่ตรวจพบว่ามีข้อมูลพร้อมครบตามเงื่อนไขของระบบ
- การเปลี่ยน Quarter จะล้าง cache ของหน้ารายงานและโหลดข้อมูลของ Quarter ใหม่
- หากขึ้นเครื่องหมาย `✕` หรือข้อความ **ไม่มี Quarter พร้อมครบ** ให้ตรวจชื่อ Tab และไฟล์ JSON ของ Quarter นั้น
- รูปแบบชื่อ Quarter ต้องเป็น `YYYY-Q1` ถึง `YYYY-Q4` เช่น `2026-Q2`

## 2. ขั้นตอนการทำงานที่แนะนำ

ทำงานตามลำดับนี้เพื่อให้ข้อมูลในหน้าถัดไปสัมพันธ์กัน

1. ไปที่ **เลือกกองทุน** เพื่อค้นหา กรอง และติ๊กกองทุนที่ต้องการ
2. กำหนดสี Highlight ให้กองทุนสำคัญ สีจะถูกนำไปใช้ในหน้าวิเคราะห์ที่เกี่ยวข้อง
3. ตรวจผลตอบแทนใน **กองทุนไทย Annualized Return** และ **กองทุนไทย Calendar Year**
4. ตรวจ Master Fund ใน **Master Fund Annualized Return** และ **Master Fund Calendar Year**
5. ตรวจ **ค่าธรรมเนียม**, **ปัจจัยประกอบอื่นๆ**, **Income Fund** หรือ **Robustness Fund** ตามวัตถุประสงค์
6. ใช้ปุ่มคัดลอกตารางหรือรูปภาพเพื่อนำผลไปวางใน PowerPoint
7. บันทึกงานค้างที่ **บันทึกข้อมูล** หรือบันทึกเหตุผลการคัดเลือกที่ **Fund Selection Logs**

> หลายหน้าจะอ้างอิง “กองทุนที่เลือก” จากหน้า **เลือกกองทุน** หากหน้ารายงานว่างหรือรายการไม่ครบ ให้กลับไปตรวจว่าติ๊กกองทุนไว้แล้วหรือไม่

## 3. ภาพรวมเมนู

### ช่วยเหลือ

#### คู่มือการใช้งาน

แสดงไฟล์ `README.md` ฉบับนี้ภายในระบบ

#### เตรียมข้อมูล

ใช้แปลงข้อมูล Raw จากไฟล์ใน Google Drive และบันทึกลง Google Sheets/JSON ประจำ Quarter

1. เลือกประเภทชุดข้อมูล
2. เลือกไฟล์ต้นทางและกด **ดึงข้อมูล**
3. ตรวจ Preview ชื่อคอลัมน์ และกำหนด Type ของข้อมูล
4. ระบุ Tab ปลายทาง เช่น `2026-Q1`
5. กด **บันทึกข้อมูล** เมื่อ Preview ถูกต้อง
6. ตรวจความพร้อมและบันทึกข้อมูลเป็น JSON สำหรับใช้เป็นข้อมูลสำรอง

หากพบคอลัมน์ชื่อซ้ำ ใช้ **เปลี่ยนชื่อซ้ำอัตโนมัติ** หรือ **ลบคอลัมน์ซ้ำ** ก่อนบันทึก

#### เตรียมข้อมูลจาก SEC

ใช้ดึงและรวมข้อมูลจาก SEC API ผ่าน workflow ของระบบ

1. กำหนดชุดข้อมูล ช่วงเดือน และ `proj_id`/`fund_class_name` ที่ต้องการ
2. กด **รัน GitHub Actions**
3. กด **ตรวจสถานะ Tabs** เพื่อยืนยันว่าข้อมูล Raw พร้อม
4. กด **รวบรวมข้อมูล** เพื่อสร้าง Master View
5. โหลด Preview และตรวจโครงสร้างคอลัมน์
6. บันทึกลง Tab ปลายทางและส่งออก JSON

ฟังก์ชันนี้เป็นงานเตรียมข้อมูลสำหรับผู้ดูแล ควรตรวจ Preview ทุกครั้งก่อนเขียนข้อมูลปลายทาง

### ภาพรวม

#### แดชบอร์ด

แสดงจำนวนรายการสำคัญและทางลัดไปยังหน้าที่ใช้งานบ่อย ได้แก่ เลือกกองทุน รายงานผลตอบแทน และคู่มือ

#### บันทึกข้อมูล

ใช้บันทึกชุดกองทุน Highlight ตัวกรอง และสถานะงานปัจจุบันเป็น Draft

- ตั้งชื่อและใส่รายละเอียดก่อนกดบันทึก
- กด **โหลด** เพื่อกลับมาทำงานต่อจาก Draft เดิม
- ใช้ **บันทึกทับ** เมื่อต้องการอัปเดต Draft เดิม
- การลบ Draft เป็นการลบรายการที่บันทึกไว้ ควรตรวจชื่อให้ถูกต้องก่อนลบ

### กองทุน

#### เลือกกองทุน

หน้าหลักสำหรับสร้างรายชื่อกองทุนที่จะนำไปวิเคราะห์

- ค้นหาด้วยชื่อกองทุนหรือ Fund Code
- กรองตาม Category, Type, Style และนโยบายปันผล
- คลิกหัวตารางเพื่อเรียงข้อมูล
- ติ๊ก Checkbox เพื่อเลือกกองทุน
- เลือกสี Highlight เพื่อแยกกลุ่มหรือระดับความสำคัญ
- กด **รีเซ็ต** เพื่อล้างตัวกรองของหน้านี้

#### แก้ไขข้อมูลกองทุน

ใช้กำหนดความสัมพันธ์ระหว่างกองทุนไทยกับ Master Fund

- ค้นหาและเลือกกองทุนไทย
- เพิ่ม Master Fund ได้มากกว่าหนึ่งกอง
- กรอก ISIN/Master ID และ Weight ของแต่ละกอง
- ตรวจผลรวม Weight และผลกระทบต่อหน้ารายงาน
- กด **บันทึก Mapping** เพื่อบันทึก หรือ **ลบ mapping** เพื่อล้างค่าที่กำหนดเอง

#### แก้ไขข้อมูลกอง Master Fund

หน้านี้ยังเป็นพื้นที่เตรียมไว้สำหรับการพัฒนา ยังไม่มีแบบฟอร์มแก้ไขข้อมูลในเวอร์ชันปัจจุบัน

#### กองทุนไทย Annualized Return

แสดงผลตอบแทนกองทุนไทยตามช่วงเวลา พร้อมมุมมอง **Return**, **Percentile** และ **Rank**

- สลับมุมมองของตารางด้านซ้ายและขวาได้อย่างอิสระ
- คลิกหัวคอลัมน์เพื่อเรียงลำดับ
- ใช้สี Highlight จากหน้าเลือกกองทุนเพื่อช่วยติดตามรายการ

#### กองทุนไทย Calendar Year

แสดงผลตอบแทนรายปีของกองทุนไทย

- กดปุ่มปีเพื่อแสดงหรือซ่อนปีที่ต้องการ
- สลับมุมมอง Return, Percentile และ Rank No.
- คลิกหัวตารางเพื่อเรียงตามปีหรือข้อมูลกองทุน

#### Master Fund Annualized Return

แสดงผลตอบแทนย้อนหลังของ Master Fund โดยใช้ Master FundId จาก AVP Thai Fund for Quality จับคู่กับ AVP Master Fund ID และระบุ Share Class ด้วย ISIN พร้อม Rank ประกอบ

#### Master Fund Calendar Year

แสดงผลตอบแทนรายปีของ Master Fund สามารถเลือกปีและเรียงข้อมูลจากหัวตารางได้

#### ค่าธรรมเนียม

เปรียบเทียบค่าธรรมเนียมรวมและรายละเอียดรายกองจากข้อมูล SEC/Master Fund ใช้ตรวจ TER และค่าใช้จ่ายที่เกี่ยวข้องก่อนสรุปผลการคัดเลือก

#### เปรียบเทียบค่าธรรมเนียม

หน้านี้เป็นพื้นที่เตรียมไว้สำหรับรายงานเปรียบเทียบค่าธรรมเนียมเพิ่มเติม

#### อัตราส่วนวัดผลการดำเนินงาน กองทุนไทย

แสดงกราฟและตารางเปรียบเทียบ Return, Standard Deviation, Sharpe, Sortino, Information, Treynor Ratio และ Maximum Drawdown ของกองทุนไทยที่เลือก โดยใช้ข้อมูลจาก AVP Thai Fund for Quality ระบบจะแสดงเฉพาะ Metric และ Period ที่มีค่าจริง

#### อัตราส่วนวัดผลการดำเนินงาน Master Fund

แสดงกราฟและตารางเปรียบเทียบ Sharpe, Sortino, Information Ratio และ Treynor Ratio

- เลือกโหมด Annualized หรือ Calendar
- เลือก Period ที่ต้องการ
- คลิกสีข้างชื่อกองทุนเพื่อปรับสีบนกราฟ
- ลากตำแหน่งชื่อบนกราฟ และกด **รีเซ็ตตำแหน่งชื่อ** เมื่อต้องการคืนค่า
- กด **ดาวน์โหลด SVG** เพื่อนำกราฟไปใช้ต่อ

#### ปัจจัยประกอบ กองทุนตราสารหนี้

ระบบมีสองหน้ารายงาน

- หน้าแรก: Fund Size, Duration, Turnover และ Yield to Maturity
- หน้าที่สอง: Asset Allocation, Rating, Holdings และข้อมูลความเสี่ยง

ข้อมูลบางช่องสามารถแก้ไขเป็น Override และบันทึกด้วยปุ่ม **บันทึกข้อมูลแก้ไข**

เปรียบเทียบ Max Drawdown ของ Master Fund รายปี 2016–2025 พร้อมกองทุนไทยที่เชื่อมโยงกัน
แถบสีแดงแสดงขนาดการขาดทุน และสามารถคลิกหัวปีเพื่อเรียงข้อมูลได้

- เพิ่มช่วงวันที่ใน Capture Date Builder
- ซ่อน/แสดงเส้นกราฟและปรับสีของแต่ละสินทรัพย์

## 4. การคัดลอกและส่งออก

หน้ารายงานที่รองรับจะแสดงปุ่มสำหรับคัดลอกหรือส่งออกข้อมูล

- **คัดลอกตาราง:** คัดลอกแบบมีรูปแบบเพื่อวางใน PowerPoint/โปรแกรม Office
- **คัดลอกรูป:** สร้างภาพจากการ์ดหรือตารางที่แสดงอยู่
- **Export Excel/CSV:** ส่งออกรายการไปตรวจสอบหรือใช้งานต่อ
- **ดาวน์โหลด SVG:** เหมาะสำหรับกราฟที่ต้องการขยายโดยไม่แตก

ควรตรวจจำนวนกองทุนและคอลัมน์ที่แสดงก่อนคัดลอก เพราะผลลัพธ์จะยึดตามตัวกรอง การเรียง และมุมมองปัจจุบัน

## 5. การเตรียม Quarter ใหม่สำหรับผู้ดูแล

1. สร้าง Tab ใหม่ใน Google Sheets ที่เกี่ยวข้อง โดยตั้งชื่อรูปแบบ `YYYY-QN`
2. เตรียมข้อมูลหลักให้ครบทั้งชุดกองทุนไทย Master Fund Key Performance และ SEC
3. ส่งออก Local/Drive JSON โดยใช้ชื่อ Quarter เดียวกัน
4. ตรวจว่าระบบตรวจพบ Quarter ใหม่และ Dropdown สามารถเลือกได้
5. เปิดหน้ารายงานหลักทุกหน้าเพื่อตรวจจำนวนรายการ หัวคอลัมน์ และวันที่ข้อมูล

ไฟล์ตั้งค่าหลัก:

- `js/config.js` — Google Client ID, Sheet ID และ Tab ตั้งต้น
- `js/config.override.js` — โหมดแหล่งข้อมูลและตำแหน่งไฟล์ JSON
- `Data/` — ข้อมูล JSON และฐานข้อมูลสำรองในเครื่อง
- `fund_server.py` — Local Server และ API สำหรับ Draft/ข้อมูลภายในโปรเจกต์

## 6. การแก้ไขปัญหา

### เข้าสู่ระบบไม่ได้

- ตรวจว่าเปิดผ่าน `http://` หรือ `https://` ไม่ใช่ `file://`
- ตรวจ `CLIENT_ID` ใน `js/config.js`
- รอ Google Identity Services โหลดเสร็จแล้วลองใหม่
- ตรวจว่าบัญชี Google มีสิทธิ์อ่าน Sheet ขององค์กร

### Token หมดอายุหรือโหลด Google Sheets ไม่สำเร็จ

กดออกจากระบบ แล้วเข้าสู่ระบบใหม่ หากยังไม่สำเร็จให้ตรวจสิทธิ์ของบัญชีและการเชื่อมต่ออินเทอร์เน็ต

### Quarter ไม่ปรากฏ

- ตรวจชื่อ Tab ให้ตรงรูปแบบ `YYYY-QN`
- ตรวจว่าข้อมูลและ JSON ที่ระบบต้องใช้มีครบ
- รีเฟรชหน้าเว็บหลังอัปเดตข้อมูล

### หน้ารายงานว่าง

- ตรวจ Quarter ปัจจุบัน
- กลับไปหน้า **เลือกกองทุน** และติ๊กรายการก่อน
- ล้างตัวกรองหรือกด **รีเซ็ต**
- ตรวจข้อความสถานะแหล่งข้อมูลบนหน้า

### หน้าเว็บโหลดช้า

- ลดจำนวนกองทุนที่เลือก โดยเฉพาะ Top 10 Holding และข้อมูล FT
- ใช้ตัวกรองก่อนโหลดตารางขนาดใหญ่
- หลีกเลี่ยงการสั่ง Sync หรือโหลดข้อมูลหลายชุดพร้อมกัน
